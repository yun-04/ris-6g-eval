# RIS-6G Link-Level Evaluation

  Python simulation code for the paper:

  > Y. Zhao, M. Ji, Z. Li, "Performance Analysis and Robust Phase
  > Configuration of RIS-Assisted Wireless Communications for 6G."

  ## Files
  - `ris_sim.py` — main simulation script (BER, rate, quantization,
    deployment geometry, CSI-error sweeps)
  - `plot_style.py` — matplotlib styling helpers

  ## Requirements
  - Python 3.9+
  - numpy, scipy, matplotlib

  ## Reproducing the figures
  python ris_sim.py

  All seven figures (Fig. 1–7) and Table II values are produced from
  this single script.
